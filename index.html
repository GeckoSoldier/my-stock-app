設定

スマホとPCでデータを共有するための同期設定です。

1. 同期方法

接続用リンクをお持ちの場合

同期済みの端末で表示した「接続用リンク」を貼り付けて「接続」を押すと、下の2と3を入力しなくても接続できます。

2. Firebase 接続情報

Firebaseコンソールの「プロジェクトの設定」→「マイアプリ」に表示される const firebaseConfig = { ... }; の部分を、コピーしたまま貼り付けてください（書き換えは不要です）。

3. 共有コード（家族・世帯コード）

同じコードを入力した端末同士でデータが共有されます。長めのランダムな文字列を推奨します。

他の端末を追加する

新しいスマホやPCを同期に加えるための、接続用リンクとQRコードを表示します。新しい端末でQRコードを読み取るか、リンクを開くだけで接続できます。

このリンクとQRコードには共有コードが含まれています。同期したい家族にだけ渡し、SNSなどには載せないでください。

iPhoneで「ホーム画面に追加」したアプリを使う場合：QRコードをカメラで読むとSafariで開いてしまうため、リンクをコピーして、ホーム画面のアプリの「設定」→「接続用リンクをお持ちの場合」に貼り付けてください。
