# 日用品ストック管理アプリ

日常の消耗品（トイレットペーパー、洗剤、シャンプーなど）の「買い物リスト」と「購入サイクル（何日ごとに買うか）」「残量」を管理するWebアプリです。

---

## クイックスタート（はじめての方はここから）

一番迷わないのは、GitHub Pagesという無料サービスでこのアプリを公開し、発行されたURLをスマホ・PC両方で開く方法です。パソコンの操作（ブラウザでクリックするだけ）のみで完了し、コマンド入力は不要です。**この作業は一度、PCで行うことをおすすめします**。

### ステップ1：GitHubアカウントを作る

1. https://github.com/ にアクセスし、「Sign up」から無料アカウントを作成します（すでにお持ちならログイン）。

### ステップ2：新しいリポジトリを作り、ファイルをアップロードする

1. 右上の「＋」→「New repository」をクリック（または https://github.com/new を開く）。
2. Repository name に好きな名前（例：`my-stock-app`）を入力し、Public を選んで「Create repository」。
3. 作成後の画面で「uploading an existing file」というリンクをクリック（または「Add file」→「Upload files」）。
4. ダウンロードしたzipファイルを**解凍**し、中の `shopping-cycle-app` フォルダの中身（`index.html`・`app.js`・`styles.css`・`manifest.json`・`sw.js`・`icons`フォルダなど）を、アップロード画面にまとめてドラッグ＆ドロップします。
5. 画面下の「Commit changes」をクリックしてアップロードを確定します。

### ステップ3：公開（GitHub Pages）を有効にする

1. リポジトリ画面上部の「Settings」タブを開く。
2. 左メニューの「Pages」をクリック。
3. 「Build and deployment」→「Source」を **Deploy from a branch** にし、Branch を **main** ／ フォルダを **/ (root)** に設定して「Save」。
4. 1〜2分待つと、ページ上部に `https://（あなたのユーザー名）.github.io/（リポジトリ名）/` というURLが表示されます。

### ステップ4：スマホ・PCで開く

1. 発行されたURLを、スマホのブラウザとPCのブラウザ、両方で開きます。
2. これだけでもう使えます（この時点ではデータは各端末の中だけに保存されます＝同期なし）。
3. スマホ：ブラウザの共有メニューから「ホーム画面に追加」を選ぶと、アプリのアイコンとして使えます。
   PC：ブラウザのアドレスバーにあるインストールアイコンから追加できます。

スマホとPCで**データそのものを共有したい**場合は、下の「クラウド同期を設定する」に進んでください。

## できること

- 商品画像は「写真をアップロード」（スマホで撮影・写真ライブラリから選択）か「画像のURL」を選べる。写真は端末内で小さく縮小して保存・同期（追加のサービス不要）。一覧でタップすると拡大表示、URLの場合はそのページを開く
- 設定タブの「リマインド」から、毎日決まった時刻（初期値18:00）の予定をGoogleカレンダーまたはiPhoneなどのカレンダーに登録。予定のリンクからアプリの「今買うもの」を直接開ける
- 商品ごとに購入サイクル（例：30日ごと）を登録。残量は前回購入日と購入サイクルから自動で推定（65〜30%は「半分程度」）。手入力（十分・半分程度・少ない・なし）も可能
- 商品ごとに「場所・店」（スーパー、ドラッグストアなど）を登録し、一覧のカテゴリの下に表示。場所・店の一覧は設定タブで自由に追加・削除でき、同期中は全端末で共通
- 「半分以下」タブに、残量が半分以下（推定残量65%以下）で「今買うもの」に入っていない商品を、残りが少ない順に一覧表示（次の買い物の候補）
- 登録画面に過去4回までの購入日履歴と平均購入サイクルを表示し、ボタン1つで購入サイクルに反映（小数点以下切り上げ）
- 「今買うもの」タブに、サイクルが近い商品・残量が少ない商品を自動で表示
- 「買った（補充）」ボタン1つで、次回のサイクルを自動計算
- 「今買うもの」から「買った」を押した商品は、その日はグレー表示＋「今日購入済み」で残り、翌日には消える（同期中の他の端末でも同じ）
- スマホのホーム画面・PCのデスクトップに「アプリ」として追加可能（PWA）
- Firebaseを使った端末間の自動同期（任意）。商品に加えて、カテゴリと「まもなく」の日数も全端末で共通になります
- 同期済みの端末に表示される「接続用リンク・QRコード」で、新しい端末をかんたんに追加
- データのエクスポート／インポート（JSONファイル）

> **リマインドについて**：OSの通知（プッシュ通知）は行いません。アプリを開いたときに「今買うもの」タブにサイクルが近い商品が表示される仕組みです。

## クラウド同期を設定する（2026年9月時点のFirebase画面）

同期にはGoogleの無料サービス「Firebase」を使います。無料枠（Sparkプラン）で足ります（Firestoreは1日あたり読み取り5万回・書き込み2万回、保存1GiBまで無料）。
コンソールを日本語表示にしている場合、ボタン名が少し違うことがあるので英語表記も併記しています。

### 手順A：プロジェクトを作る

1. https://console.firebase.google.com/ にGoogleアカウントでログインします。
2. 「プロジェクトを作成」→ 好きな名前（例：`my-household`）を入力して作成します。途中の「Gemini」「Googleアナリティクス」はオフのままで構いません。

### 手順B：Firestoreデータベースを作る

1. 左メニューの「**データベースとストレージ**（Databases & Storage）」→「**Firestore**」を開きます（見つからない場合は画面上部の検索欄に「Firestore」と入力）。
2. 「**データベースを作成**（Create database）」をクリックします。
3. エディションは「**Standard エディション**」を選んで「次へ」。
4. **データベースIDは `(default)` のまま**にします（別の名前にするとこのアプリでは同期できません）。
5. ロケーションは `asia-northeast1 (Tokyo)` を選びます（後から変更できません）。
6. セキュリティルールは「**本番環境モード**（Production mode）」を選び、「作成」をクリックします。

### 手順C：セキュリティルールを設定する

1. Firestoreの画面上部の「**ルール**（Rules）」タブを開きます。
2. 最初から入っている文字をすべて消し、同梱の `firestore.rules` の中身を貼り付けて「**公開**（Publish）」をクリックします。

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // 「共有コード」を知っている人だけがそのデータを読み書きできます。
    // 匿名ログイン済みであることのみを条件にしたシンプルなルールです。
    // 共有コードは第三者に推測されにくい、ある程度長いランダムな文字列にしてください。

    // ===== MEGURU（めぐる） =====
    // TODOデータ
    match /meguru/{code}/tasks/{taskId} {
      allow read, write: if request.auth != null;
    }
    // カテゴリ・場所・「今やること」の判定日数などの共有設定
    match /meguru/{code}/meta/{docId} {
      allow read, write: if request.auth != null;
    }

    // ===== 日用品ストック管理（同じFirebaseプロジェクトを使う場合は残してください） =====
    match /households/{code}/items/{itemId} {
      allow read, write: if request.auth != null;
    }
    match /households/{code}/meta/{docId} {
      allow read, write: if request.auth != null;
    }
  }
}
```

> このルールは、同じFirebaseプロジェクトを使う別アプリ「MEGURU（めぐる）」と共通です。日用品ストック管理が使うのは下半分の `households` の部分（商品データと、カテゴリ・場所・店などの共有設定）です。

このルールは「匿名ログインしていれば読み書きできる」というシンプルな内容で、「共有コード」を知っている人だけが実際のデータにたどり着ける想定です。共有コードは長くランダムな文字列にしてください（アプリの「コード生成」ボタンで作れます）。

### 手順D：匿名ログインを有効にする

1. 左メニューの「**セキュリティ**（Security）」→「**Authentication**」を開き、初めてなら「始める」をクリックします。
2. 「**ログイン方法**（Sign-in method）」タブで「**匿名**（Anonymous）」をオンにして保存します。

### 手順E：ウェブアプリを登録して接続情報をコピーする

1. 「プロジェクトの概要」の右にある**歯車アイコン**→「**プロジェクトの設定**」を開きます。
2. 「全般」タブを一番下までスクロールし、「**マイアプリ**」の枠にある「**</>**」（ウェブ）アイコンをクリックします（アプリが既にある場合は「アプリを追加」→「</>」）。
3. ニックネームを入力し、「Firebase Hosting も設定する」はチェックせずに「**アプリを登録**」。
4. 表示される `const firebaseConfig = { ... };` の部分をコピーします。
   - あとで確認したいときは、同じ「マイアプリ」の中の「SDK の設定と構成」で「構成（Config）」を選ぶと表示されます。

### 手順F：アプリに入力する

1. アプリの「設定」タブ →「クラウド同期する」を選びます。
2. 手順Eでコピーしたものを、**そのまま**「Firebase 接続情報」の欄に貼り付けます（書き換え不要）。
3. 「コード生成」を押して共有コードを作ります。**このコードはメモしておき、スマホでも同じものを使います。**
4. 「保存して接続」を押します。この端末に登録済みの商品がある場合は「クラウドにコピーしますか？」と聞かれるので、「OK」を押すとそのまま引き継げます。
5. 緑色で「接続しました」と表示され、画面右上が「同期中：〇〇」になれば成功です。
6. 2台目以降の端末は、下の「新しい端末を追加する」の方法が簡単です（同じFirebase設定・同じ共有コードを手で入力しても接続できます）。

### 新しい端末を追加する（接続用リンク・QRコード）

1. すでに同期している端末で「設定」タブを開き、「**他の端末を追加する**」→「接続用リンクとQRコードを表示」を押します。
2. 新しい端末で、次のどちらかを行います。
   - **QRコードをカメラで読み取る**：開いたページで「接続しますか？」と聞かれるので「OK」を押します。
   - **リンクを貼り付ける**：「リンクをコピー」でコピーしたリンクを、新しい端末のアプリの「設定」→「クラウド同期する」→「接続用リンクをお持ちの場合」に貼り付けて「接続」を押します。
3. 右上が「同期中：〇〇」になれば完了です。

> **iPhoneで「ホーム画面に追加」したアプリを使う場合**：Safariとホーム画面のアプリは保存場所が別々です。QRコードをカメラで読むとSafariで開いてしまうので、リンクを貼り付ける方法でホーム画面のアプリに入力してください。

> 接続用リンクとQRコードには共有コードが含まれています。同期したい家族にだけ渡し、SNSなどには載せないでください。

## 安全対策（2026年10月の見直し）

- 画像のURLは「http://」「https://」で始まるもの（または画像そのもののデータ）だけを使います。「javascript:」などの危険なURLは保存・表示しません。
- アップロード写真の欄には、このアプリが作った画像データだけを表示します（外部URLを入れられても通信しません）。
- インポートしたファイル・同期で届いたデータ・端末に保存されたデータは、使う前に決まった形に整え、おかしな値は捨てます。
- ページに Content Security Policy（CSP）を設定し、万一スクリプトが紛れ込んでも動かないようにしています。
- 共有コードの「コード生成」は、推測されにくい安全な乱数（約80ビット）で作ります。
- 接続用リンクから接続するときは、この端末のデータを自動でコピーする提案はしません（知らない人のリンクだった場合の情報漏れ防止）。今と違う同期先に切り替わる場合は確認画面で警告します。

## データのバックアップ

設定タブの「データをエクスポート」で、登録した商品データをJSONファイルとして保存できます。「インポート」から復元できます。

## 困ったときは

- アプリを更新したのに画面が変わらない → ページを再読み込みしてください。それでも変わらない場合は、ブラウザの「サイトデータの削除」を一度行ってください。
- 「保存して接続」で赤いメッセージが出る → メッセージに原因（匿名ログインが無効、ルール未設定など）が表示されるので、その箇所を確認してください。
- スマホとPCでデータが違う → 共有コードが完全に一致しているか確認してください（大文字・小文字も区別されます）。
