# 日用品ストック管理アプリ

日常の消耗品（トイレットペーパー、洗剤、シャンプーなど）の「買い物リスト」と「購入サイクル（何日ごとに買うか）」「残量」を管理するWebアプリです。

---

## クイックスタート（はじめての方はここから）

一番迷わないのは、GitHub Pagesという無料サービスでこのアプリを公開し、発行されたURLをスマホ・PC両方で開く方法です。パソコンの操作（ブラウザでクリックするだけ）のみで完了し、コマンド入力は不要です。**この作業は一度、PCで行うことをおすすめします**（スマホだけでもできますが、ファイルのアップロードがPCの方が簡単です）。

### ステップ1：GitHubアカウントを作る

1. https://github.com/ にアクセスし、「Sign up」から無料アカウントを作成します（すでにお持ちならログイン）。

### ステップ2：新しいリポジトリを作り、ファイルをアップロードする

1. 右上の「＋」→「New repository」をクリック。
2. Repository name に好きな名前（例：`my-stock-app`）を入力し、Public を選んで「Create repository」。
3. 作成後の画面で「uploading an existing file」というリンクをクリック（または「Add file」→「Upload files」）。
4. ダウンロードしたzipファイルを**解凍**し、中の `shopping-cycle-app` フォルダの中身（`index.html`・`app.js`・`styles.css`・`manifest.json`・`sw.js`・`icons`フォルダなど）を、アップロード画面にまとめてドラッグ＆ドロップします。
   - フォルダごとドラッグすれば `icons` フォルダの中身も含めてアップロードされます。
5. 画面下の「Commit changes」をクリックしてアップロードを確定します。

### ステップ3：公開（GitHub Pages）を有効にする

1. リポジトリ画面上部の「Settings」タブを開く。
2. 左メニューの「Pages」をクリック。
3. 「Build and deployment」→「Source」を **Deploy from a branch** にし、Branch を **main** ／ フォルダを **/ (root)** に設定して「Save」。
4. 1〜2分待つと、ページ上部に `https://（あなたのユーザー名）.github.io/（リポジトリ名）/` というURLが表示されます。

### ステップ4：スマホ・PCで開く

1. 発行されたURLを、スマホのブラウザとPCのブラウザ、両方で開きます。
2. これだけでもう使えます。「＋商品を追加」から試してみてください（この時点ではデータは各端末の中だけに保存されます＝同期なし）。
3. スマホ：ブラウザの共有メニューから「ホーム画面に追加」を選ぶと、アプリのアイコンとして使えるようになります。
   PC：ブラウザのアドレスバーにあるインストールアイコン（＋やモニターのマーク）から追加できます。

これで基本的な使い方は完了です。スマホとPCで**データそのものを共有したい**場合のみ、下の「クラウド同期を設定する」に進んでください。

> **PCだけですぐ試したい場合**：解凍したフォルダの中の `index.html` をダブルクリックするだけでも、ブラウザでそのまま動作確認できます（GitHubの手順は不要）。ただしこの方法はスマホからは開けません。

---

## できること

- 商品ごとに購入サイクル（例：30日ごと）と残量（十分・少ない・なし）を登録
- 「今買うもの」タブに、サイクルが近い商品・残量が少ない商品を自動で表示
- 「買った（補充）」ボタン1つで、次回のサイクルを自動計算
- スマホのホーム画面・PCのデスクトップに「アプリ」として追加可能（PWA）
- Firebaseを使った端末間の自動同期（任意）
- データのエクスポート／インポート（JSONファイル）

> **注意（リマインド機能について）**：このアプリはOSの通知（プッシュ通知）は行いません。アプリを開いたときに「今買うもの」タブでサイクルが近い商品が自動的に表示される仕組みです。買い物前にアプリを開く習慣をつけるのがおすすめです。

## クラウド同期を設定する（スマホとPCでデータそのものを共有したい場合）

同期には、Googleの無料サービス「Firebase」を使います。クレジットカード登録不要の無料枠で問題なく使えます。

### 手順A：Firebaseプロジェクトを作る

1. https://console.firebase.google.com/ にアクセスし、Googleアカウントでログインします。
2. 「プロジェクトを作成」→ 好きなプロジェクト名（例：`my-household`）を入力 → 作成します（Google Analyticsは無効のままで構いません）。
3. 左メニューの「構築」→「Firestore Database」を開き、「データベースの作成」をクリックします。
   - ロケーションは `asia-northeast1`（東京）などお好みで選択
   - セキュリティルールは「テストモードで開始」を選んでいったん作成します（後で下記のルールに置き換えます）
4. 左メニューの「構築」→「Authentication」を開き、「始める」→「Sign-in method」タブから「匿名」を有効にします。
5. プロジェクトの設定（歯車アイコン→プロジェクトの設定）の「マイアプリ」から「</>（ウェブ）」アイコンをクリックしてウェブアプリを追加します（アプリ名は何でもOK、Hostingの設定は不要）。
6. 表示された `firebaseConfig` というJSON形式の設定（`apiKey`や`projectId`などが入ったもの）をコピーします。あとでアプリに貼り付けます。

### 手順B：セキュリティルールを設定する

同梱の `firestore.rules` の内容を、Firebaseコンソールの「Firestore Database」→「ルール」タブに貼り付けて「公開」してください。

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /households/{code}/items/{itemId} {
      allow read, write: if request.auth != null;
    }
  }
}
```

このルールは「匿名ログインしていれば読み書きできる」というシンプルな内容です。あなたが発行する「共有コード」を知っている人だけがデータにアクセスできる想定ですが、厳密な認証ではないため、他人に知られると困るような機密情報の保存には向きません。心配な場合は、共有コードを長くランダムな文字列にしてください（アプリの設定画面の「コード生成」ボタンで自動生成できます）。

### 手順C：アプリに接続情報を入力する

1. アプリ（GitHub Pagesで開いたページ）の「設定」タブを開きます。
2. 「クラウド同期する」を選択します。
3. 手順Aでコピーした `firebaseConfig` のJSONを、そのまま貼り付けます。
4. 「コード生成」ボタンを押すか、好きな文字列（家族・世帯を表すコード）を入力します。**このコードはスマホとPCで必ず同じものを使ってください。**
5. 「保存して接続」を押します。画面上部に緑色の●と「同期中：〇〇」と表示されれば成功です。
6. もう一方の端末でも同じURLを開き、同じ手順で同じFirebase設定・同じ共有コードを入力すると、データが自動的に共有されます。

## データのバックアップ

設定タブの「データをエクスポート」で、登録した商品データをJSONファイルとして保存できます。同期を使わない場合は、定期的にエクスポートしておくと安心です。「インポート」から復元できます。

## 困ったときは

- GitHub PagesのURLを開いても真っ白 → アップロード後1〜2分待ってから再度アクセスしてみてください。`index.html` がリポジトリのトップ階層に置かれているか（サブフォルダに入っていないか）も確認してください。
- 同期状態が「同期エラー」になる → Firebase設定のJSONに誤りがないか、Firestoreのルールが公開されているか、匿名認証が有効になっているかを確認してください。
- スマホとPCでデータが違う → 共有コードが完全に一致しているか確認してください（大文字・小文字も区別されます）。
